# filo 1.1.2

The whole More button now responds to clicks, and installation is now a simple drag to Applications.

**[Download for Mac](https://github.com/Audiofool934/filo/releases/download/v1.1.2/filo-macos-universal.dmg)** · [ZIP alternative](https://github.com/Audiofool934/filo/releases/download/v1.1.2/filo-macos-universal.zip) · [Installation](https://github.com/Audiofool934/filo/blob/main/docs/INSTALL.md)

macOS 14.4+ · Apple Silicon and Intel · Version 1.1.2, build 10

## What's changed

- Fixed missed clicks in the top and bottom of the glass ellipsis button.
- Added a universal DMG with a Retina installation background and an Applications shortcut.
- The DMG and ZIP are Developer ID signed and Apple-notarized, with notarization tickets included.
- Kept ZIP as an alternative download, with SHA256SUMS covering both files.
- Release verification checks the actual DMG and ZIP payloads, signatures, notarization, and version.

## Install or update

Open the DMG, drag filo to Applications, eject the image, and open filo from Applications.
When updating, first disconnect and quit the existing app through **••• → Quit filo**.
macOS may show its normal downloaded-app confirmation.
See the [installation guide](https://github.com/Audiofool934/filo/blob/main/docs/INSTALL.md) for details.

The app and DMG are signed with Developer ID and notarized by Apple.
`SHA256SUMS` covers both downloads; after downloading it alongside the packages, run `shasum -a 256 -c SHA256SUMS` to verify them.

Apple Music format matching and the fixed 44.1 kHz Spotify profile are unchanged.
**Matched** describes the observed format match, not a certification of end-to-end bit-perfect audio.
