# filo 1.1.2

The whole More button now responds to clicks, and the Mac download includes a drag-to-Applications DMG.

- Fixed missed clicks in the top and bottom of the glass ellipsis button.
- Added a universal DMG with a Retina installation background and an Applications shortcut.
- The DMG and ZIP are Developer ID signed and Apple-notarized, with notarization tickets included.
- Kept ZIP as an alternative download, with SHA256SUMS covering both files.
- Added an opt-in Developer ID and notarization workflow using Keychain credentials.
- Packaging now builds in isolation and verifies the actual DMG and ZIP contents before producing final artifacts.

This source targets version 1.1.2, build 10.
Apple accepted both the app and DMG submissions, and Gatekeeper identifies them as Notarized Developer ID.
The app extracted from the final ZIP also passes ticket validation and Gatekeeper assessment.
See the [installation guide](../INSTALL.md#first-launch) for the normal first-launch confirmation.
