# filo 1.1.1

A smaller ƒ, a steadier card, and a simpler way to get started.

## Download and start

Download **filo-macos-universal.zip**, unzip it, and move **filo.app** to Applications.
One app supports Apple Silicon and Intel on macOS 14.4 or later.
The asset has a stable name so the [download link](https://github.com/Audiofool934/filo/releases/latest/download/filo-macos-universal.zip) continues to work with future releases.

The app is ad-hoc signed and **not Apple-notarized**; macOS may block its first launch.
Read the [installation guide](https://github.com/Audiofool934/filo/blob/v1.1.1/docs/INSTALL.md) for the first-launch flow for this version.
SHA256SUMS accompanies the download.

## What's changed

- A custom, compact ƒ replaces the generic link icon in the menu bar.
- The status item keeps a fixed 20-point width, with no sample-rate label changing its spacing.
- An arrowless rounded card replaces the popover, retaining the fixed layout and native glass materials.
- The project page now introduces the app with a real screenshot, direct download, and concise setup instructions.
- A feedback form makes it easier to report how filo works with your Mac and DAC.

Apple Music format matching and Spotify's fixed 44.1 kHz profile retain their existing behavior.
Matched reports agreement with observed format information, not end-to-end bit-perfect certification.
The default Format matching path needs no extra audio driver or recording permission.

The bundle is version 1.1.1, build 9.
Native Apple Silicon checks covered the connection switch, details navigation, fixed card size, and Escape dismissal.
The universal bundle passed strict signature and architecture checks; native Intel execution and every macOS version were not rechecked for this patch.
